# Signal Atlas 信号图谱

把投资消息还原为可追溯的事件证据链。面向需要快速核实信息的个人投资者、财经编辑与初级投研人员。

## v3 侦探档案版

v3.1 已整合神笔小羊的统一视觉：档案纸页面/阅读区、深靛英雄/头卡/弹窗、暗红线索、档案金和浅蓝节点。英雄图使用其交付的原创素材，压缩为约78KB WebP；组件保持HTML/SVG真实交互。默认“档案主题”与“明亮阅读主题”均为纸面阅读，导航/头卡保留深色层次。实施说明见 VISUAL_HANDOFF.md，原始设计参考位于 design/，不参与生产页面渲染。

- 原创侦探证据室视觉，v3.1 按神笔小羊方案统一背景与组件，不使用官方角色或剧照。
- 时间机 2.0：日期滑轨、键盘方向键、版本节点与原下拉联动；首版不展示未来事实与解读，单版本显示真实空态。
- 证据星图：真实原文到版本的引用关系；点击来源查阅原文、点击版本回放。移动端默认等价列表，可手动切换。
- 30 秒头卡：事实、产品解读、未证实范围，附当前版本官方出处。
- 版本对照：选择任意更早基准，展示前后事实、状态变化、新增原文和文字高亮。高亮不冒充官方撤回。
- 信号护照：真实生成可预览、下载的 PNG 长图，含所选时点之前的轨迹、引用编号、完整官方 URL、核验时间与风险提示；保留 Markdown 导出和图片失败降级。

未实现第六项反方审查；没有接入生成式 AI、实时采集或外部通知。星图不编造反驳材料。历史版护照使用当时中性标题，避免标题泄漏后续终止结果。

## 数据与范围

本库收录 **30 个事件、32 份官方原始文档、36 个事实版本**，覆盖并购监管、资本运作、宏观政策、AI 算力、AI 应用、财报和消费科技。以上统计从 knowledge.json 实际计算，不是页面装饰数字。

案例包括 NVIDIA 收购 Arm 终止、股票拆分、两季财报、Blackwell 样品交付；Apple Vision Pro 美国及地区扩展、Apple Intelligence 上线、回购授权、财报、M4 iPad 与 iPhone 16；美联储 2024 年三次降息及欧洲央行 6 月降息。

在原14条历史档案基础上新增16条近期官方披露，发布日期为2026-09-24至2026-10-27，涵盖Apple新品/Siri AI、NVIDIA合作/供应链/软件、ECB四类调查和美联储金融监管/家庭财务调查。近期来源为4家发布机构，不声称全面覆盖A股或全球市场。选题、原文要点和边界见 RECENT_EVENTS.md；核验文本保存在 artifacts/recent-sources/（审阅包，不部署）。

资料覆盖2020–2024历史案例与2026年近期披露，抓取核验在2026-10-27完成。**“当前版本”仅指本库最后收录版本，不代表已覆盖事件此后的全部进展，也不是实时资讯或行情。** 每个官方文档有直达链接、发布日期、中文摘要和核验时间。未知发生时间为空，不编造时分；旧档案保留原收录时间。新品发售、投资交割、扩产和监管提案不会因为已经发布公告就标记为完成。

## 可以实际操作的功能

- 多关键词、股票代码、主体和领域检索；类别/状态/收藏筛选；排序和分页。
- 事件全量切换：摘要、关联资产、观点、证据和版本同步。
- 历史时间机器：只用当时已收录的材料，避免未来事实泄漏到过去。
- 事实/观点/推测/传闻筛选；归档没有的类型提供诚实空态。
- 每条事实的官方出处与四种时间查看；全局证据库和原始文档检索。
- 收藏/取消、关注列表和回放变化动态；存储到当前浏览器。
- 分享事件深链接、导出带出处的 Markdown 研究卡片、关联事件跳转。
- 深浅主题、键盘焦点、Esc 关闭弹窗、/ 聚焦搜索、减弱动效支持。
- 六步虚构变化演练：传闻、官方意向、推测、更正、否认、过期。演练与真实历史库严格分开。
- 数据加载错误、重试、保留最后成功数据、本地存储损坏与不可用处理。

## 核心设计

### 同一事件与版本

本版本使用人工核验的事件 ID，以主体、动作、对象、报告期和地区区分事件。一个文档可能支持多个不同动作，但不会因此被计为多个独立信源。例如 Apple 同日财报与回购授权分别建事件，NVIDIA Q1/Q2 分报告期，Vision Pro 美国上市与新地区扩展分动作。

事件版本只追加，不覆盖原公告。NVIDIA 收购 Arm 由“计划阶段”变为“已终止”，历史公告仍可回看。事件间通过标签与主体生成关联列表。

### 事实与证据

官方文档支持其确实披露的内容。产品分析标为观点，推测和传闻不升级成事实。不能把“没有披露”当作“否认”，不能把“授权回购”当作“已经全部执行”。

证据覆盖率 = 当前事实记录在“官方出处、披露日期、收录记录、独立发生日期”四项完整度的等权平均。它不是可信概率、胜率或投资建议。相同文档的引用不会增加独立文档数。

### 四种时间

- 事件发生时间：只有独立依据时填写，如拆股完成于 2024-06-07。
- 披露时间：原文日期；保留日期级精度，不编造小时。
- 抓取/核验时间：本次建库核验的 UTC 时间。
- 更新时间：本地档案录入/修订时间，独立于原文发布日期。

### AI 角色与使用记录

开发过程中使用 AI 做信息架构、编码、交互文案、测试草稿和来源中文摘要。摘要对照已访问的官方页面核验；原始链接保留供进一步检查。运行时没有调用外部 LLM，不把规则与编辑摘要冒称为实时 AI 推理。

生产接入可让 AI 候选聚类、分类和提取字段，再通过来源白名单、时间校验、原文引用和人工纠错约束结果。当前未接入 iFinD MCP 或扶摇，不显示虚构价格和涨跌幅。

## 运行与部署

这是无需构建的静态站，运行时不依赖 npm 或第三方字体。Vercel 直接部署当前目录，Framework 选择 Other，Build Command 留空，Output Directory 为当前目录。也适用于其他静态托管。

本地开发只用于改动验证：

```sh
python3 -m http.server 4387 --bind 127.0.0.1
```

测试：

```sh
npm ci
npx playwright install chromium
npm test
npm run test:ui
npm run test:dossier
npm run test:sources
```

UI 测试默认访问 http://127.0.0.1:4387，可用 TEST_URL 指向公开站点。需先运行本地静态服务。Playwright 仅为开发依赖，不进入用户页面。

## 边界与未做

- 历史精选样本集中于 Apple/NVIDIA 和宏观政策，尚未覆盖 A 股全市场，不声称大规模实时知识库。
- 未做实时采集、外部 AI 推理、数据库、云端账户同步、邮箱/飞书/系统推送。
- 收藏只在同源当前浏览器持久化；更换域名或设备不会自动迁移。
- 站内动态是用户触发的历史回放变化，不冒充刚发生的市场消息。
- 未提供真实股价、持仓收益、买卖建议和交易能力。
- 独立来源冲突自动推理尚未上线；当前提供官方计划与终止对照、历史回放和独立演练。
- 公开可用不等于授权复制；只保存必要摘要和链接，不复制全文及付费内容。
- 原长期站点能否更新取决于所属 Vercel 项目的有效授权。可访问网页不等于持有该项目写权限。
