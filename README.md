## 2. 目标用户与核心任务

面向个人投资者、财经编辑与初级投研人员。痛点不是消息不足，而是同一事件散落在多条消息中，难以辨认最初出处、后来改了什么以及哪些结论仍成立。

核心流程：搜索事件 → 阅读事实/解读/边界 → 历史回放 → 对比变化与原文 → 关注及导出。源码版还支持：新材料 → 候选归并 → 分类与冲突提示 → 人工确认 → 追加版本 → 已关注事件站内通知。

## 3. 核心设计

### 同一事件与版本

历史库人工维护稳定事件 ID，以主体、动作、对象、报告期、地区区分事件。同公司不同报告期分别建档；同一公告支持不同事件仍只计一份独立文档。

材料处理台按标题、正文、发布方与事件词项交集推荐一个候选，不是语义模型，也不提供可信概率。用户可确认或放弃，尚不能改选多个候选。事实型输入确认后追加版本，不覆盖旧材料；无匹配时建立待分类档案。重复 URL 不重复计数；早于或等于当前版本日期的材料停止写入，不支持历史回填。

### 类型、冲突与证据权重

- 历史证据区分官方事实与产品观点；没有推测/传闻时显示空态。
- 输入分类器只有“事实候选、推测、传闻”三类，依赖关键词；**没有独立的观点自动分类器**。推测/传闻进入会话复核队列，不改事实结论。
- 终止、否认、更正以关键词触发状态或替代关系提示。规则不能可靠解决复杂否定、局部否认、多个主张及冲突范围。
- 权重是“编辑核验官方材料优先、观点分层、未证实不升级”的定性规则；**没有独立信源加权或概率裁决模型**。
- 证据覆盖率 = 官方出处、披露日期、收录记录、独立发生日期四项完整度百分比的等权平均。它不是可信度、事件概率或投资胜率。

**人工确认不是事实认证。** 输入只检查必填项、日期格式和 HTTPS 前缀，没有自动抓取原文或核验发布方身份。任意 HTTPS 链接可能进入规则处理，必须由用户核对来源；页面“事实”标签不能证明内容真实或官方。

### 四种时间

| 字段 | 当前处理 |
| --- | --- |
| 发生时间 | 有独立依据才填；多数档案为空，不将披露日自动当发生日 |
| 披露时间 | 官方日期，精度到天，不编造时分 |
| 抓取/核验时间 | 归档核验记录，不等于原文发布时刻 |
| 档案更新时间 | 目前与该版本收录/核验时间同值，尚无独立服务端修订日志 |

### 更新与通知

确认新材料后，已关注事件生成旧/新状态、原因、发布方及处理时间的站内未读记录；原文 URL 在版本证据查看，不直接附在通知卡片。通知仅在本浏览器内，不向其他真实用户广播。

更正/否认/过期可在独立的六步虚构演练中体验。**真实库没有自动过期调度器或完整撤回机制。** 关注事件的回放记录明确标为“历史回放”，不冒充刚发生的市场更新。

## 4. 已实现交互

- 多词、代码、主体、领域搜索，状态/关注筛选、排序与分页。

- 历史滑轨、版本节点与键盘切换，只展示选中版本及以前的事实。
- 任意更早版本对照、文字高亮及新增来源；高亮不是官方撤回。
- 证据星图与移动端等价列表、四种时间与官方链接。
- 关联资产解释路径及关联事件；不编造价格、收益。
- 关注/取消、站内动态、深链接、Markdown 与 PNG 护照导出。
- 材料处理台、去重、人工确认、会话复核队列、未读提醒（源码版）。
- 原创侦探档案主题、统一圆角、两种阅读主题、窄屏和减少动效。
- 加载错误、重试、最后成功数据保留、损坏/禁用存储降级。

## 5. 数据使用与追溯

`knowledge.json` 是唯一静态基线：14 条 2020–2024 历史案例，16 条 2026-09-24 至 2026-10-27 披露，主要来自 Apple、NVIDIA、美联储与欧洲央行。它是精选样本，不是 A 股全市场或实时知识库。“当前版本”仅指本库最后收录版本，不保证包含此后所有进展。

每个版本以 `sourceIds` 指向官方 URL、发布机构、披露日和必要中文摘要；不提供付费全文。初始 `checkedAt` 为 2026-10-27，交付复查不改写旧核验时间。URL/标题可达检查不等于逐句语义验证。

## 8. 已知边界与未做

- 未做运行时生成式 AI、实时采集、真实行情、交易、持仓收益或投资建议。
- 未做数据库、云端账户、多用户同步、外部推送或服务端审计。
- 关注与动态在同源当前浏览器持久化；材料新版本和复核队列仅保留当前页面会话，刷新恢复静态基线。
- 未做多主张裁决、数值权重、语义聚类、来源身份认证、完整时间合法性验证、候选改选及历史回填。
- 不能把局部否认一律视为全事件终止，也不能把计划/授权当已执行；规则需要人工审慎确认。
- 未完成真实 Safari/Firefox、全部设备与人工读屏验收；自动扫描不代表全面无障碍通过。
- 原指定旧快照尚缺材料入口及正确背景路径；已上线新版生产域名，但不能让旧快照自动升级。
